# Lucas Blog

个人技术博客，记录 AI 实践、技术踩坑和效率方法。

## 技术栈

**框架：** Astro 5 + Tailwind CSS 4  
**部署：** Vercel  
**图表：** Mermaid  

## 文章结构

```
src/data/blog/
└── 2026/           # 按年份归档
```

## 本地开发

```bash
pnpm install
pnpm dev
```

## 部署

推送到 `main` 分支，Vercel 自动构建部署。
