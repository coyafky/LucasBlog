# 今天：用 AI 套图踩坑，以及我见过的最实在的学习方法

**今天就一个核心结论：ChatGPT 生成商品详情页套图这条路，暂时还不好用，但它的思路值得记住。**

---

## 今天做了什么

**早：给销售装上了 Hermes sales agent**

帮一个销售同事部署了公司最新版的 Hermes sales agent，顺带把他公司云服务账号也启了。流程比预期顺利，但没有想象中"一键搞定"的程度——账号权限那块还是需要人工介入。这部分值得记下来，下次帮人部署心里有数。

**中午：研究抖音店的生图视频**

主要研究抖音店铺的生图视频规范。学到的一个具体知识点：**抖音的生图规格是 4:3**，不是常见的 1:1 或 16:9。这个在内容分发时候要注意，不然平台会裁切。

然后开始测试用 ChatGPT 生成商品详情页套图。

**测试 ChatGPT 生成套图：可控性不够**

流程是这样的：先定义产品有什么特点 → 挖掘产品对应人群 → 人群推使用场景 → 不同页面位置写不同 Prompt → 对接生图模型出图。

理论上这个链路很顺。但我实际测下来，**可控性不够**——生图出来的效果和你预期有较大偏差，特别是对产品细节的还原。这不是工具的问题，是 prompt 和产品之间的语义 gap。我现在对"AI 生成详情页套图"这个需求的态度是：**方向对，但还没到可以稳定出产的阶段**。

**下午：发票 + 公众号对接**

处理了一些行政流程上的事情。对接了公众号，发现一个感受：AI agent 相关的需求确实多，但"落地"这件事不是纯技术问题。

**刷到一个观点，部分认同**

看到一个小红书帖子说 AI 落地看三点：①业务②安全③人和人之间的交际。

我部分认同。业务和安全是对的，但人和人之间的交际这点——我更认同的是**AI 落地需要人来推动，而推动的人需要懂技术又懂业务**。纯靠"沟通"解决不了认知差距。

**发现一个好工具：多平台营销看板**

今天在 Twitter 上刷到一个针对海外营销的看板系统，支持 Facebook、Twitter、Pinterest 等多平台统一写文案、发内容。这和我们之前构想的"营销部工作流自动化"方向一致。目前还没落地，但这个竞品工具值得研究。

**和朋友聊了一个感受**

他说 985 的同学"眼界也没有那么大"。我的回应是：他们不是不厉害，只是**习惯处理当前事情，对新事物的接触动力没有那么大**。这和我自己在做的事情形成了一个对照——我是被压力推着走，他们是惯性向前走。两种路径都能到目的地，但 AI 这个窗口期，惯性可能不够用。

---

## 一个重要的决策

**先做竞品数据爬取，再做内容 Agent。**

我有一个想法：先爬取各个轻改装品牌的商品图片和数据，然后用 AI 做竞品监控。有了别人的数据，才能做内容写手，才能给老板交差。这个顺序不能反——没有数据基础，内容 Agent 是空中楼阁。

今天的内容密度很高。从 AI 套图测试，到 Hermes agent 学习，到发票行政，到竞品工具发现，到和朋友聊天——这些看起来散，但其实都指向同一个方向：**在 AI 工具越来越多的时候，真正的竞争壁垒是对业务的理解深度，以及把工具落地的执行速度。**
