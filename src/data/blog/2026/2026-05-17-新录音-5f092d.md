做营销流量体系，不能只会用抖音

周日。本来想休息，结果脑子里一直在转一个事：**品牌营销的流量体系怎么做？**

## 今天干了什么

报价的事还没完——要跟供应商重新对，减预算、减功能。另一边公众号注册卡在财务打款上，打不了款就开不了号，文章也发不了。

但真正花时间想的是**流量渠道怎么搭**。

我把中国的流量渠道扫了一遍，盘出三个层次：

| 层次 | 渠道                               | 特点               |
| ---- | ---------------------------------- | ------------------ |
| 公域 | 抖音、B站、小红书、AIGO            | 流量大，竞争也大   |
| 垂直 | 汽车之家、懂车帝、什么值得买、易车 | 精准用户，适合软文 |
| 私域 | 公众号、视频号                     | 可控，但需要内容养 |

不同平台的风格差异很大。小红书和抖音的对比特别强烈——一个偏种草，一个偏冲动。皮皮虾反而适合做长视频、有原理深度的内容。论坛就老老实实做软文。

## 一个判断

> **不能只押一个平台，但也不能全铺。要用内容匹配渠道属性。**

所以我想搭两套系统：

1. **竞品监测系统** — 爬竞品的小程序（陈美车居、改装类的），分析他们的产品结构、文案策略、流量来源。用 OpenStylei 把网站IA化后再爬，这样连B站热点、小红书内容都能抓。

2. **销售 Agent** — 把云上的销售系统接上产品知识库，再把销售书籍用 Bruce 转成 skill，嵌入到 agent 里。遇到销售场景直接生成话术。老销售说没必要，新销售觉得有用——我的判断是：**对新人的过渡期有价值。**

## 一个具体成果

排班表这件事——飞书导出来是一大坨数据，手动剪很烦。我发现用 `lark-cli` 可以自动化处理。这个我要做成一个计划，跑起来就省了每周重复劳动。

## 一个真实的反思

这周工作太猛了，周末也在想事。

看书少了。整理的书买了几本，理财的意识冒出来了一下，但都没落地。我知道看书重要，但总是「知道这回事，不上手」——**知道和理解之间有差距，理解会融会贯通之间又有差距。**

AI 能力再强，自己不实操，工具摆在那也不会变成自己的。

## 接下来的事

1. 跟供应商敲定减配后的报价方案
2. 跟进财务打款，完成公众号注册 + 第一篇文
3. 把品牌营销系统的技术方案写出来（竞品监测 + 销售 Agent）
